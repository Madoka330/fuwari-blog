## 第十三周

`2026-06-01 - 2026-06-07` 

这一周是实践周，还是讲的 Java 项目开发。上课的时间只有下午，所以我们的时间很多很多。老师不像上学期那样咄咄逼人，而是讲得很慢，讲得很细致，让大家都能跟上。其实实践周我都或多或少有一点伤感，明明喜欢超前学习的我，却没有在 Java 学习上花费太多时间，也没有在学习上花费太多时间。

有一天我突发奇想，我想在宿舍里做吃的，这个想法已经在我脑海中出现了很久很久，一直没有实践。首先我想到的是买一个蒸蛋器，因为我喜欢吃蛋。因此我要考虑几个问题，第一个鸡蛋采购的问题。学校里面没有冰箱，现在也是炎炎夏日，鸡蛋估计只能放一周。然后我每天可能吃 2 个，也可能只吃 1 个，索性我一下子通过京东买了 10 个鸡蛋。接下来就是解决怎么让生鸡蛋变成熟鸡蛋，我决定使用蒸蛋器，感觉最安全。到货之后，我发现了另一个问题，就是鸡蛋要如何储存，放在哪里储存？因为炎热，储存的话就要放在阴冷的地方，于是我选择学校的储物柜里面。我看购买鸡蛋页面的温馨提示，它说到货之后请快速把鸡蛋从泡沫里拿出来，而且放鸡蛋的时候最好大头在上小头在下。我也看了 AI 给我的小建议，它说可以用纸箱和硬纸板做一个放鸡蛋的容器。于是就有了下面这个东西——

![](https://img.lunamyth.love/2026/06/鸡蛋-1780908299420.jpg)

后面我又改进了一下，比如下面不应该垫卫生纸，因为容易变得很潮湿，我便换成了废弃的 A4 纸。当然了，这样肯定不是长久之计，我当机立断买了一个 3×5 规格的储存鸡蛋的盒子，明天就能到货！现在就到了激动人心的煮鸡蛋的环节——拿出商家赠送的量杯，加入 70ml 的水，把洗净的鸡蛋平稳放在蒸格上，盖上盖子，按下启动开关，大约 10 分钟就可以关闭开关食用鸡蛋了。溏心蛋很好吃，自己煮的东西很好吃，我希望我能做更多吃的。

在这种想法的驱动下，我开始物色其他好东西。首先我肯定要买一个电煮锅，打开京东一看，原来小功率的电煮锅才 300w，这比我买的蒸蛋器的功率还低，果断下单。当时我买那个蒸蛋器还有一个原因是这个蒸蛋器可以热牛奶，不过我之前的马克杯坏了，于是我就采购了一个新的带盖的杯子。但当我测试热牛奶的时候，才发现杯子大了，蒸蛋器小了，很是令我苦恼。我便想看看有没有有没有定位就是牛奶加热器的东西，后面果然找到了一个。它长得很像杯垫，功率特别低，而且可以长时间保温，我便买了这个。

我开始幻想，我开始幻想我有一天可以在寒冷的冬日涮牛肉吃，我开始幻想自己做饭的那一天。不过啊，这一切都在一天早晨阿姨的查寝结束了……我犯蠢了，我的蒸蛋器放在了一个非常明显的位置，阿姨一眼就认出来没收了，我还签了字。我心情全无，我似乎一瞬间就从自己做饭的幻想回到血淋淋的现实——我还有好多作业没做。我不知道，我准备来完成 JavaWeb 的期末作业，我又开始用 ai 来生成愚蠢的代码了。好烦，好烦，中午我也不想吃饭，也不想听下午的课。可是逃课的畏惧占了上风，我换掉了睡衣，点了份 KFC，无精打采的前往了教室。后续就是我扔掉了还没有煮完的鸡蛋，我退掉了没有拆封的电煮锅，我把可以加热的杯垫藏在了储物柜最深处……

我一直都有一个想法，就是在我的床上装一个平板支架，这样我就可以躺在床上看动画，看漫画，串流玩视觉小说了。到货之后我才发现一个很严重的问题，因为宿舍的床的结构太老旧了，所以我甚至找不到一个合适的地方安置这个支架。最后在床尾找到了一个位置，一个非常非常坏的位置。最后我干脆就不用支架了，直接用手拿着平板看漫画也挺舒服的。

说实话，又是没有学习的一周，现在已经见惯不怪了。唯一算得上是一点学习的只有两件事，一件事情是我找到了一种新的调用 deepseek api 的方法，之前的 continue 调用实在是太难用了。首先我是无意之中发现可以在 vscode 里面使用 deepseek 官方出的插件，搭配 能够直接调用 v4 模型，搭配 copilot 使用。大大提高了我的前端开发效率。第二个是有一天晚上我睡不着，想起来我的 telegram 手机端的最近用不了了，官方说对于中国地区的短信接收服务要收取费用，但是我根本没有任何支付方式可以做到这一点。我便想有没有什么解决方法，开始上网查阅资料，最后找到一种解决方法。先下载 telegram 的老版本，再通过已经登录的 Web 端接收验证码，登录成功之后去官网下载 telegram 的最新版本覆盖即可。虽然我用 telegram 的机会比较少，但是偶尔想用的时候总不能没有吧。

比较幸运的是，这周我没有把百合给落下。一部是水群的时候无疑了解到的一部，名字叫做《虽然很抱歉但我不是百合》。据说有三人行剧情，我又特别喜欢这样的剧情，我便打开百合会开始品鉴。剧情很有意思，有亲亲，有涩涩，还是我喜欢的群像。不过美中不足的是这个是百合后宫，不很不喜欢这种情感不对等的作品。不过只要没心没肺一点，只要没有喜欢的 cp，其实后宫也还好。但是啊，我错了，这部作品自从女主的学妹出来之后我就一直很喜欢这一对——她们俩是高中的死对头，她们同在一个运动社团，学妹为了和女主一起比赛所以就唯独对女主严厉要求，使得女主很怕她。后来女主升上了高中，而学妹依旧在读初中。一次偶然机会她们俩又相遇了，女主本来想把媚药给她，从来好趁机欺负她。但是学妹肯定不会相信这种来路不明的东西，骗了女主往其他地方看，自己趁机便倒掉了媚药。女主以为她已经喝掉了媚药，所以就直接对她说你喜不喜欢我，没想到学妹一下子就害羞了，女主还问学妹你到底喜欢我哪里。后来又有一次，学妹来到女主的家中，女主故技重施，学妹也故技重施。女主说如果这是真的就好了，如果学妹不是喝了媚药才对她好就好了，后来学妹便告诉了女主实情。有一次女主的妹妹想和女主更亲近一点，于是偷偷给女主下了媚药。女主果然中计了，不过她心中完全没有想着妹妹，而是浮现出了学妹的身影。她马上前往了自己的房间锁上了门，给学妹打电话，说喜欢你，而且在媚药的加持下，她还说我们做彼此的女朋友吧。女主就这样一边想着学妹，一边自己做。后面一次比赛中，女主在最后终于接住了她初中一直接不住的球，因为在那一瞬间她想起来了初中时学妹给她的训练，似乎顿悟了，成功接住了这个球。

唉，所以现在我看见这部作品中女主和其他女性有越界行为我就犯恶心，果然后宫作品不能投入真感情啊……

这周我又继续看魔法少女奈叶，这次我看的是那两部我还没有看过的剧场版 Reflection 和 Detonation。因为前面我看的那两部总集篇删除了很多小细节，增加了更加绚丽的战斗，所以我对那两部总集篇的印象一般。这次我也是抱着这样的念头来看这两部全新剧场版，没想出质量之高出乎我的意料。我的观看地点并不算很好，一半时间在吵杂的教室里，一半时间在颠簸的客车中，但是我的心却随着这两部剧场版的剧情而跳动，期间流过不止一次眼泪。

> 今天一口气看完了《魔法少女奈叶》的两部剧场版《Reflection》和《Detonation》，真的太好看了。我本以为自己的心境已经失去了曾经的热情，没想到即使是在客车上这样颠簸的环境下，我依然看得津津有味。果然我还是最喜欢这种关于正义与善良的故事。不仅如此，这两部剧场版的百合浓度也非常的高：
> 
> 比如奈叶的那句：「我家菲特是一个善良的孩子，请不要欺负她」。还有后来阿米缇娅指定让菲特来听取口供时，维塔质问为什么要选她，奈叶在一旁理直气壮地插嘴说：「因为菲特看上去很善良」。结果，这还真的就是阿米缇娅选择菲特的理由。
>
> 不听劝阻独自前往地球的妹妹琦莉耶，以及为了防止妹妹酿成大祸紧随其后追到地球的姐姐阿米缇娅。琦莉耶虽然做了错事，但她的剖白很真实——她一直觉得不如姐姐优秀，感觉父母也更偏爱姐姐。这种自卑与渴望被认可的复杂情感刻画得十分细腻。
> 
> 在这种复杂情感下，琦莉耶一有烦心事，就会找她小时候的玩伴伊莉丝倾诉。虽然在结局时，伊莉丝残忍地坦白之前的一切陪伴都是在欺骗和利用她，但琦莉耶却哭着说：哪怕初衷是谎言，但两人曾经共同度过的美好时光是真实存在、不会改变的。
>
> 最好嗑要数夜天之书的前主人尤莉，和被麦克斯韦所长制造出来用于改善环境的伊莉丝。当回放过去的影像，看到尤莉为了改善家园环境，用魔法让那颗荒芜星球的一角瞬间变绿、开满鲜花时，看着她曾经纯真的笑容和她看到尤莉力量之后开心的泪水，再对比伊莉丝如今的疯狂与两人之间的相爱相杀，我的眼泪也像伊莉丝一样在眼眶里打转。她们曾拥有过那么甜蜜温馨的日常，好在最后所有的误会终于解除，两人能够重返家乡开启新的生活。我真的好喜欢这样的剧情。
>
> 影片结尾还有一个极具升华意义的情节：小时候的奈叶幻影拥抱了现在的自己，祈求她不要再这么不顾一切地拼命，不要再让关心她的人难过了，要学会多爱自己一点。看到这一幕，我瞬间理解了在第三季《StrikerS》中，教官时期的奈叶为什么会对那些在模拟战中乱来、不顾自身安危的昂和缇亚娜进行那么严厉的训话。曾经我不太能理解那时的奈叶，现在我彻底懂了——因为那正是她自己用血泪走过的路。
>
> 我以为我的心早已经死了，但是没想到直到现在，这些关于正义、善良与相互救赎的情感，依旧能深深地打动我。我好喜欢这些善良正义可爱的人。

这周六是蓝桥杯国赛，我们周五晚上出发前往四川大学。我们的酒店位置在一个商业圈，带队老师说这个位置的酒店要便宜不少。因为隔音效果还不错，所以酒店实际上也没有太吵。我想吃涮牛肉了，就拉着同房间的学长前往了附近的一家潮汕牛肉吃夜宵。那个时候刚十点，到店之后客人很少，因为我们来的比较晚，所以牛肉都打了折。我们点了吊龙、雪花、牛舌、牛肉丸、兔头、刀削面、宽粉和空心菜，一共花了 220 元，非常不错。饭后我再在蜜雪点了一个冰淇淋，就这样慢悠悠回到了酒店。

![](https://img.lunamyth.love/2026/06/潮汕牛肉-1780908299426.jpg)

说起来比赛体验一般，有几点可以说说：首先是因为我到教室的时间比较晚，于是只能坐在别人选剩下的座位上。我刚找到一个位置坐好，就感觉到寒冷无比，原来我头顶就是冷风。键盘打字延迟特别高，后面才了解到原来是因为考试机的内存只有 4G。比较好笑的事情是，考试机默认的 pdf 阅读器内有 AI 插件，于是被蓝桥杯的监考系统检测到了，直接电脑锁屏。不过因为我平时都用 Chrome 打开 pdf 文件的好习惯，所以并没有中招。最后一件事就是关于中午的饮食，没想到还不是志愿者一个一个人分发，而是举手示意才能拿到食物。最后就是关于我的状态呢，我感觉还好，但是因为我已经渐渐远离 ACM 了，可能最后的结果也一般吧。

这周差不多就是如此，下一周我可要多花时间看英语啊，马上又要四级了……
